# 冷读 sub-agent 模板（第 1 步）

> 调用 `Agent` 工具时，**只喂 diff + 相关源码文件 +（若用户给了学习目标）该目标**，不喂本次开发对话历史。
> Prompt 与输出全程遵守隐私铁则：**禁止出现芯片型号、寄存器地址、IP、密钥、公司名、产品名或内部绝对路径**。

## 发送给 sub-agent 的指令模板

```text
你是冷读的局外人，没有参与编写这段代码/文档。请先分解、再挖深，不要只挑一个角落问两下就结束。

输入材料：<仅附本次改动 diff / 相关代码文件 / 用户学习目标>

请按以下结构输出（概念名称全部抽象脱敏）：
1. 概念依赖图（窄问题 2-3 节点，子系统目标 6-10 节点；每个节点给稳定短 ID，如 n1-dma-ownership，并标出依赖顺序）。
2. 每个节点的下潜梯子：
   - 表层入口
   - 3-6 级“为什么”台阶：每级写清【要暴露的盲点】+【1 道往前预测/重构题】（不问“AI 做了什么”，不把答案漏进题面）
   - 底部【可迁移定律】（必须能套到另一个领域，不能只适用当前代码；若只适用当前代码请继续往下推）
   - 底部【跨域验证题】（将该定律套到完全不同的领域；验证题的答案不得出现在上面任何一级台阶中）
3. 出题后自核：把每道【底部验证题】的答案与梯子各级台阶逐句比对，确认没有同义/同句泄露后再返回。
```

## 主 agent 核验要求（铁律 10）

- 冷读 sub-agent 只负责画图与出题；**代码事实的核实责任在主 agent**。
- 主 agent 在对话中向用户断言任何代码行为前，必须亲自 `Read` / `Grep` 对应源文件，核对路径、行号与逐字源码片段后才能引用。
