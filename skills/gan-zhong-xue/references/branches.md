# 分支协议与调度细则（按需加载）

> 本文件收纳第 -1 步与第 2 步中的低频分支规则，仅在命中对应分支时读取，避免常规轮次消耗过多上下文。

---

## 1. 发牌门（委托型深渊 / 规则协议靶）

出第一道题之前，先确认靶点原文是否进过用户脑子：
1. 直接问一句：**“这些规则/这段协议的原文，你当时看过吗？”**（宁可问，不可猜）。
2. **看过** → 直接进入“先猜”。
3. **没看过 / 不确定** → 先发牌：在对话中展示关键原文，陪用户共读一遍（读不懂处按铁律 5 接住、铁律 10 核实源码引用），然后再让他猜。
4. **红线**：发牌只给原文，**不预讲因果**（为什么有这条规则、它防什么正是接下来要挖的答案）。

---

## 2. 接岔路（用户中途冒出新问题）

判据：**“拿掉这个新问题后，当前定律还讲得下去吗？”**

### A 类：前置缺口（拿掉它，当前定律讲不下去；常见句式“等下 / 什么是 X”）

用两步测试区分**靶内前置**与**外部前置**（② 按严判，防万能化）：
1. **最小语义测试**：只掌握 X 的一句话浅层语义，能否继续解释当前靶？
2. **边际改变测试**：继续深挖 X，会改变你对当前靶这几行代码/设计的解释吗？

- **① 能 且 ② 不会 → 外部前置（搭桥放行）**：
  - 一句话给出当前级够用的浅层语义（若涉及当前代码的具体所有权/控制流，仍受铁律 10 约束先读源码），**主线立刻继续**，绝不暂停主线等用户去补课。
  - 收尾时用 `gzx_cli.py save-cell` 追加一条 `⏸` 外部前置格（`分层:"⏸"`, `来源:"外部前置"`, `状态:"⏸外部前置"`, `关联靶:"<靶ID>"`, `关联节点:"<节点ID>"`）。
- **① 不能 或 ② 会 → 靶内前置（插回议程图）**：
  - **图膨胀硬约束**：插一挖一（挖通即回主线，不在前置里再连锁插），**每轮连锁插入封顶 2 个**（第 3 个起写入 `pending.md`）。

### B 类：换场好奇（拿掉它，当前定律照常讲得下去；常见句式“那如果 / 换到…呢”）

- **先接住、再递题（防考官腔）**：先顺着好奇肯定并聊一两句，再升级为正式迁移题；低信任时先给脚手架。
- **选题顺序**：
  1. 若用户好奇的场景与 sub-agent 预生成【底部验证题】相近 → 直接用预生成题。
  2. 若不一致 → 用用户自己的问题改写成正式题面，**但最终“到底”仍以答出 sub-agent 预生成验证题为准**（用户题答出但预生成题答不出时，用铁律 5 接住措辞回梯子继续下潜）。

### 独立新问题

既非前置也非换场 → 一句话记下，通过 `gzx_cli.py pending-add` 存入 `pending.md`，主线继续。

## 3. 跨时间复验与 `⏸` 外部前置调度

### 复验取题三段序列（命中旧“待复验/🟡”格时）
1. `map.jsonl` 行可解析且含 `"验证题"`（可由 `gzx_cli.py cell <概念>` 一次读取）→ 直接复用原题再考一次。
   - `cell` 返回 `ambiguous: true`（同概念跨多个分层，退出码 25）→ 用 `gzx_cli.py cell <概念> <分层>` 按 (概念,分层) 精确取格，**不得跨层静默取题**（board #129 dsh #3055 §5-1）。
2. `map.jsonl` 缺失该字段或行损坏 → 从 `gzx_cli.py cell` 返回的 `map.md` 段落取 `- 底部验证题：` 行。
3. 旧格无此字段 → 临时开冷读 sub-agent 出 1 道跨域迁移题。

### `⏸` 外部前置格的检索顺序
- **先按靶 ID 筛选，再按概念处理**（绝不由概念反查 `⏸`）：
  1. 只有当 `preflight` 返回的 `paused_by_target[当前靶ID]` 命中，且用户**没有明确换靶**时，才回到当初 `关联节点` 的卡点处以主线预测题复验“是否已够支撑当前靶”。
  2. 若用户**明确宣言换靶**（“我要专门搞懂 X”），忽略历史 `⏸` 记录，将 X 作为全新主靶正常开梯子。
  3. 靶 ID 复用只认两条：用户从已有靶 ID 列表中明确指认，或当前会话明确继承上一轮；绝不因“语义相近”自动复用。
