# 干中学 (Learning by Doing)

> 治 vibe-coding 的病：**交付物在涨，理解没跟上。**

你在用 Claude Code 高速交付。但交付物里有一部分是"甩手让 AI 做了、自己没真懂"的——AI 干活时早解释过，你没接住。这个 skill 不是再讲一遍，是**就着一段真实的、你在场的改动，逼你从"认得"走到"真懂、能复述、能迁移"**。

它是**认知健身房，不是问答 bot**。先让你猜、逼你想，不直接喂答案——**费力是功能，不是 bug**。

> 哲学锚：「知之为知之，不知为不知，是知也」/「绝知此事要躬行」/「少就是多」。

---

## 30 秒上手

```
/plugin marketplace add ly8427/gan-zhong-xue
/plugin install gan-zhong-xue@gan-zhong-xue
```

然后干你的活。干到一半想搞懂 AI 正在做的那步，或提交完回头补一个没懂的改动，对它说：

> "帮我搞懂你刚才做的这步" / "我刚才那段没懂" / "这个 commit 我说不清"

它会陪你走一轮。**建议配强模型**（Opus 级），弱模型容易倒瀑布、问法生硬。

⚠️ **请诚实说"不知道"**——不丢人，是让它接住你的信号；不懂装懂只会喂歪你的地图。

---

## 它和"再开个会话让 AI 讲一遍 repo"有什么不同

**主体是"地图"，不是"课"。** 每一轮往一张跨会话、跨时间持续存在的地图（`~/.gan-zhong-xue/`）上写一笔，带时间戳和"待复验"状态。🟢 只代表"今天理解"，真懂要靠未来命中时复验通过——这是"用你未来的行为证伪你过去的地图"。没有地图，它就退化成一次性聪明对话，护城河为零。

**两种模式**：
- **掌舵**（任务中调用）：干到一半追问 → 掌控方向、帮 AI 避开错路。回报当下兑现，最顺人性。
- **学习**（提交后回看）：补"我到底 ship 了什么"。

**冷读 sub-agent**：挖深渊时开一个不看对话历史的局外人，防"作者盲区 + 把答案漏进题目"。

## 隐私（硬门槛）

跑在你**真实工作代码**上（可能是公司代码）。硬规则：
- 地图、pending、任何总结里**禁止写入具体值**（芯片型号、寄存器地址、IP、密钥、公司名、产品名、内部路径）——只记抽象后的概念。
- **一切只落本地 `~/.gan-zhong-xue/`，永不外传、永不进任何联网报告。**

---

## 诚实的局限（请读）

- **目前所有"它有用"的证据都来自设计者本人（n=1）。** 要真证伪，需要独立被试试用——**这是公开发布前唯一该补的实验，gate 是真人不是代码。** 这次发出来，就是为了找你这样的独立测试者。
- 判断型深渊（"该改哪个 if""这架构三个月后会不会烂"）没有当场裁判，真相要等时间和线上后果——它不伪装成评分器，只训练你"诚实面对自己懂没懂"。

**你的反馈是它变好的唯一燃料。** 见下面"反馈"。
